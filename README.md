# Casa do PC — Template de loja e assistência

Este projeto contém um template front-end (HTML/CSS/JS) para a loja e assistência técnica "Casa do PC". Ele já inclui produtos e serviços (limpeza e conserto) com imagens de apoio via Unsplash.

Arquivos incluídos:
- index.html — estrutura do site com seções: Home, Produtos, Serviços, Sobre, Contato.
- styles.css — estilos responsivos, animações e layout.
- scripts.js — animações on-scroll, modal de produto/serviço, carrinho (localStorage) e handler de formulário.
- Imagens — hotlinked via source.unsplash.com (fotos reais). Substitua por fotos próprias para mais autenticidade.

Como usar:
1. Salve os arquivos em uma pasta (index.html, styles.css, scripts.js, README.md).
2. Abra index.html no navegador.
3. Para alterar produtos/serviços, edite o objeto PRODUCTS e SERVICES em scripts.js.
4. Para substituir imagens, troque as URLs nas tags <img> em index.html e nas propriedades img em scripts.js por links diretos das suas fotos (ou faça upload para seu servidor).

Recomendações para imagens reais:
- Use fotos do seu próprio perfil (envie aqui que eu atualizo).
- Para cada serviço/produto, tenha pelo menos 3 imagens (detalhe, antes/depois, embalagem).
- Converta imagens para WebP e gere thumbnails para melhorar carregamento.
